Specialization of Label Expressions

Archi supports defining a label expression on a Specialization so that diagrams can automatically use it when an element does not define its own label expression. This lets you establish consistent labeling patterns for specialized concepts across all Views.

How it works

  • If an element instance in a View defines its own label expression, that expression is used.
  • Otherwise, if the underlying model element has a Specialization with a label expression, the Specialization’s expression is used.
  • If neither is set, the element’s default name is displayed.

Editing the Specialization’s label

You can add or change a Specialization’s label expression in the Specializations Manager using the Customize label button. The dialog supports editing a single Specialization or applying a label expression to multiple selected Specializations at once.

Scope and limitations

  • Specializations apply to ArchiMate elements and relationships defined in your model. Objects like Folders, Groups, Notes, View References, and Canvas Connections do not have Specializations.
  • Folder label expressions only affect how child objects are shown in the Model Tree and are unrelated to Specialization labels.
  • Label expressions use the same syntax described in the Archi Wiki.
